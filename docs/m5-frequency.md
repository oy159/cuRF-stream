# M5：结构频率证据复验

2026-11-18，接续[当前跳几何修复](m5-recognition.md)。用户暂无 50 Ω 终端，继续软件修复，未启用噪声 / 杂散校准。
**结构估频是可选试验，默认关闭；M5 识别质量仍未通过。** run4 权重和冻结显示策略不变。

## 修复对象与实现

部分完整 DSSS 观察的原始分类概率超过 0.90，但频谱几何中心偏离实际载波约 0.9–1.1 MHz，
初次估计还会被宽轨迹固定下来，长期触发 500 kHz 频道检查。此前的中心 EMA 在 M4 出现新增错误，未采用。

新增 `--stage2-dsss-lock`，使用当前模型实际接收的 `[1024][3]` FP32 输入，独立寻找 Barker-11 结构的残余频移：

- 提取率支持 22–64 MS/s；32 tap Blackman 低通插值到 44 MS/s，分析 660 点，保留每芯片两个采样。
- 搜索 ±1.5 MHz、50 kHz 步长、44 个定时和正反码序。14 个符号分为前后各 7 个，取两半相干能量比例的较小值。
- 相干比例至少 0.80；与相距至少 300 kHz 的其他峰相比，高出至少 0.10；滤波后平均功率至少为原窗口的 0.30。
- 只有原模型 top-1 为 DSSS 且概率至少 0.90，并通过上述结构检查，才校正本条观察的频率。

GPU 与独立双精度 CPU 参考对齐；工作区和滤波表启动时分配，热路径没有新增 CUDA 分配或 FFT 计划。
这项证据只属于当前窗口，不继承给未来窗口，也不将候选吸附到 WiFi 栅格。
没有改写模型输入、概率、类别、带宽或 SNR。SNR 继续按实际提取中心计算。

原始 feed 的 `f` 为报告的载波中心；参与结构检查的观察另保留 `extraction_f`，表示实际提取振荡器中心，
以及 `dsss_frequency` 的频移、相干比例、峰差、保留功率和有效标记。
`valid` 仅表示结构检查通过；实际校正仍要求上述模型类别 / 置信条件。所有原始判决继续计入未知总量。
这不是完整的 PLCP / FCS 解码，不据此宣称协议解码或实采准确率。
`run_room_checks.py` 和 `run_live_checks.py` 的对应开关为 `--dsss-frequency-lock`，均将模式和实现哈希写入冻结清单。

## 固定输入、正反控制与回归

Python 原型在 35 个真实 DSSS 模型窗口中接受 29 个；20 个合成正控制全部通过，
232 个噪声、单音、OFDM 及正确模拟抗混叠的带外反控制无接受，反控制最高相干比例约 0.428。
带外测试先从高采样率混频再降采样；直接在低采样率上生成带外频率会产生不可区分的离散混叠，不能作为有效反控制。

最终 C++ 66/66、Python 59/59 通过。GPU 检查包含 512 行混合采样率、乱序请求、独立 stream、部分批次、
输出哨兵、输入不变及八个在途槽位与 CPU 参考逐条对齐。512 行批量和在途槽位的 GPU memcheck 均为零错误。
新增有限离线 `--stage2-input-dump PATH` 最多输出 128 条宽带模型输入；实测 147 条只写 128 条，
其余模型流仍完整保留，现有输出不可覆盖，实时 / 硬件源在打开接收机前拒绝该诊断参数。

重复基线与开启结果概率逐项一致。没有通过放宽容差来宣称逐位概率等价。

## 长测与同流重评分

使用 2450 MHz、RX2 单路及 RX1+RX2 双路，各 300 秒；容量 512 请求 / 1024 轨迹 / 128 MiB scratch / 8 在途。
显式启用 `--dsss-frequency-lock`，使用 `current` 带宽模式，显示在完整判决之后合并重复未知。
每场原始及显示 feed 各受 256 MiB 硬上限约束；没有发射或采集噪声参考。

为隔离频率校正的作用，在同一份完整原始模型流上仅把 `f` 恢复为 `extraction_f` 后重新执行冻结策略。
模型概率、类别、SNR、时间及其他字段相同，分别报告两个参考频率的命名和最长空窗。
它是同流策略重评分，不能当作第二次 IQ 推理或另一场硬件接收。

结构估频继续保留为默认关闭的可选项。仍有大量 0.3–3 MHz 候选；后续需区分独立窄信号与宽载波切片，
并修复相邻宽载波定位。单靠带宽统计不能断定这些候选都是假信号，原始未知总计继续保留。

```sh
python tools/check_frequency_evidence.py \
  --feed /path/to/ism24/raw.feed --out /path/to/ism24/frequency-effect.json \
  --seconds 300 --stream 0 --target-mhz 2442 --target-mhz 2462
```

双路的 RX2 为 stream 1。工具要求完整结束记录，核验每条频率改动的结构 / 原始分类依据，
保留输入、策略和评分代码哈希；已有报告不会覆盖。时间基准要求源起点为零。

证据位于远端 `~/dataset/m5_quality_v5`，本机摘要在 `docs/results/m5-quality-v5`。
长测标签空窗不等于真实分组漏包率；没有独立标注整个现场，也不能将所有命名当作正确标签。
